# 口袋精灵地图接入文档

## 目录约定

地图 JSON 放在：

```text
D:\gz\dx\dw\地图
```

当前已接入：

```text
地图\仓库2.json
地图\原野怪区.json
```

地图内瓦片资源仍使用 JSON 里的路径，例如：

```text
assets/map_tiles/tilesets/00.png
assets/map_tiles/special_variants/*.png
```

## JSON 格式

每张地图需要包含：

```js
{
  "width": 15,
  "height": 20,
  "tileSize": 16,
  "tilesets": [],
  "specialTiles": [],
  "cells": []
}
```

`cells` 长度必须等于 `width * height`。每个格子支持：

```js
{
  "base": {},
  "upper": {},
  "block": false
}
```

`block: true` 表示不可行走。

## 当前地图切换规则

已在 `app.js` 中接入：

- 玩家在 `仓库` 走到地图最下面一行，进入 `原野怪区`。
- 玩家在 `原野怪区` 走到地图最上面一行，返回 `仓库`。

当前逻辑地图名和文件名映射：

```js
仓库 -> 地图/仓库2.json
原野怪区 -> 地图/原野怪区.json
```

切换后会同步重置角色和宠物位置，宠物跟随路径会清空。

## 野怪规则

`原野怪区` 中移动会累计步数：

- 进入原野后有冷却，避免刚进图立刻遇怪。
- 移动一段距离后有概率遇到野怪。
- 当前野怪：`阿木木`
- 当前使用资源：`895.chj`
- 攻击动作：`896.chj`

## 新增地图接入步骤

1. 把新地图 JSON 放入 `地图` 目录。
2. 文件名作为地图名，例如 `森林.json` 对应地图名 `森林`。
3. 确认 JSON 内资源路径能从项目根目录访问。
4. 在 `app.js` 的 `handlePlayerStepStarted()` 里添加传送规则。
5. 如果需要遇怪，在对应地图名分支里添加步数或概率触发。

## 关键函数

```js
loadMap(name)
changeMap(name, tileX, tileY)
placeActorAt(tileX, tileY)
handlePlayerStepStarted(direction, targetX, targetY)
startWildBattle()
```

多人显示会按 `mapName` 过滤，不同地图的玩家不会显示在当前地图上。
