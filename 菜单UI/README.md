# 菜单 UI

## 快捷操作

`quick-menu-hotkeys.js` 管理数字快捷路径：首位按一级菜单页签编号，后两位按当前可见子菜单的编号选择，最多三级。例如 `92` 打开区域地图，`142` 在队伍指令中选择第二项。输入路径的 850ms 有效期内，数字会被快捷操作独占，不会触发方向、确定或返回映射。

负责主菜单、二级菜单和物品图标上的纯客户端显示效果。

## 物品数量

`item-quantity-display.js` 使用 `item-quantity-digits.png` 的 0-9 精灵图渲染数量。

- 1-99：数字覆盖在物品图标中心。
- 100 及以上：图标显示 `99`，物品名后显示 `（N组）`，每组为 100 个并向上取整。
- 该模块仅改变显示，不参与背包、经济或服务端结算。
