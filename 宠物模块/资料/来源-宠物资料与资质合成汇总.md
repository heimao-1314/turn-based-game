## 2. 字段说明

本文五项资质统一按以下顺序记录：

```text
攻击 / 生命 / 速度 / 法力 / 防御
```

截图里的资质不是最终战斗属性。正式系统需要经过资质、属性点、百分比、装备和上限管线，才能得到战斗属性。

“带出等级”暂按玩家携带等级要求理解，不等同于宠物当前等级。截图中的召唤宠物大多标注带出等级 1。

同一宠物可以拥有多个天生技能。资料卡的“天生技能”字段只列技能名，并用“、”分隔；“天生技能说明”按相同顺序逐项列出每个技能的目标、必中、消耗、公式和状态参数，不因多技能重复建立宠物卡。

“天生技能说明”同时作为后续“技能说明查看”功能的权威原始文案，不能只保存计算参数。每个技能必须保留完整文字、显式换行和颜色分段：技能标题使用 `gold`，普通叙述和标点使用默认白色，精力/生命等消耗与危险提示使用 `red`，伤害公式、属性变化和关键数值使用 `green`，状态名称可使用 `gold`。展示顺序统一为“技能名 → 类型/目标与消耗 → 伤害或治疗公式 → 状态效果与持续回合 → 命中率/叠加/解除规则”；原图存在剧情或风味描述时另存风味文案，不得覆盖机制说明。纯文本说明保留 `\n` 作为无样式回退，彩色版本按 `dialogLines[].segments[] = { text, color }` 记录，不能依赖 HTML 字符串或临时正则着色。

### 4.4 卷轴设计结论

召唤道具需要同时保存：

```json
{
  "summonPoolId": "pet_pool_xxx",
  "qualificationRoll": {},
  "selectionMode": "random_or_select",
  "tradePolicy": "never_tradeable",
  "requestId": "uuid"
}
```

新区规则现已确认：只有野宠的出生资质浮动，捕捉/生成时将浮动结果写入宠物实例；神兽、魂兽、圣兽、S圣兽、SS圣兽、珍奇、绝世、战魂宠、北极活动宠等非野宠使用固定模板资质。所有宠物实例仍需保存资质来源、提资、宝石和合成结果，但不能把非野宠的固定模板资质当成随机值。

宠物1级时五项属性点均为0；每项仅存在1个隐藏自然成长单位，用于执行“加权资质 ÷ 属性换算常量 × `petQualificationScale`”的资质换算。该隐藏单位不直接显示为属性、不允许分配或洗点，也不计入1243点养成总账；从2级开始才增加零转固定属性点。

修炼经验正式规则：每本宠物修炼册提供100点经验；当前进化等级 `L`（0～99）完成下一次突破需要 `round(100 + L × 300 / 99)` 点，100次突破总需求25,000点，即250本修炼册。每次经验满后必须消耗1本神品或魂品宠物进化书，0级到100级共需要100本进化书；经验溢出保留到下一进化等级，当前阶段经验满后禁止继续消耗修炼册。

转生正式规则：宠物达到100级后最多转生2次。未转生、1转、2转分别使用独立的1～100级普通经验曲线，最高状态为2转100级。每次转生使用宠物转生宝石，放入1个成功率75%，放入2个成功率100%；1个判定失败时宠物转生宝石仍然消耗。转生成功后普通等级回到1级、普通经验清零；进化等级、进化随机天赋点、可分配天赋点和已分配天赋点全部保留。转生请求、宠物转生宝石数量、概率和结果必须由服务端记录。

宠物1级默认亲密度为100、潜力为15。零转普通升级每次获得亲密度100、潜力150；转生后保留当前值且不因重新升级重复获得，潜力最高15000。宠物达到属性上限后禁止继续投入，洗点使用宠物洗点卡，每次消耗1张。

潜力防御的“防御总资质”正式定义为基础防御资质池（原始防御资质+资质卡防御资质）与红色/加成防御资质池（资质宝石镶嵌提升）之和，不使用攻击、生命、速度、法力五项资质合计。`gemCard` 只记录资质宝石来源，不在红色/加成池中重复计算。潜力10000时转换系数为0.18，潜力15000时为0.27，统一公式为 `防御总资质 × potential × 0.000018`；结果继续接受法宝、天赋和贴纸的防御百分比加成。

野宠出生资质正式采用四档：差（白色40%）、中（蓝色30%）、良（红色20%）、优（金色10%）。捕捉时按带出等级读取五项资质各自的最低/最高范围，每项独立抽取档次和值。新区正式生成范围为单调递增：1级攻击700～1150、生命850～1200、速度850～1200、法力800～1200、防御1000～1400；5级为750～1350、850～1250、850～1350、850～1350、1050～1500；15级为850～1500、900～1400、900～1500、900～1500、1100～1650；25级为950～1600、950～1500、950～1600、950～1600、1150～1800；35级为1050～1700、1000～1600、1000～1700、1000～1700、1200～1950；45级为1100～1800、1050～1700、1050～1800、1050～1800、1300～2050；55级为1150～1900、1100～1800、1100～1900、1100～1900、1400～2200；65级为1200～2000、1150～1900、1150～2000、1150～2000、1500～2350；75级为1250～2100、1200～2000、1250～2100、1250～2100、1600～2500。具体宠物可在对应范围内按天生技能定位调整上下沿，但不得突破等级全局边界；旧资料卡中的资质数字全部保留为历史证据，不作为新区出生范围。

野宠捕捉正式规则：使用宠物精灵球；野宠初始抵抗值随机为6～12，每个精灵球消耗1个并随机降低1～3点抵抗值，抵抗值归零后捕捉成功。背包满时不能捕捉且不消耗精灵球；捕捉结果固定为1级。允许重复宠物和同名宠物，每只实例使用唯一 `instanceId`；可用宠物改名卡改名。新捕捉宠物默认为未绑定，未绑定宠物可交易、放生；绑定后不可交易。

野宠所有战斗主动天生技能统一消耗10点精力，非战斗技能不消耗精力；同一技能类别在一只宠物上只能存在一个。

零转 1～100 级五项固定点：99 × 5 = 495

### 12.1 宠物资质提取器

已确认规则：

- 宠物资质提取器只有一个档位，提取比例为 50%。
- 提取器按来源宠物五项资质的比例提取，总资质值为来源宠物可提取总资质的 50%。
- 提取时直接消耗来源宠物，来源宠物及其培养、装备和资质状态一并失效。
- 提取结果生成携带五项资质的宠物资质宝石。
- 资质宝石镶嵌给新的宠物后，新宠物获得宝石携带的资质加成，并显示为红色/加成资质。

完整数据流：

```text
来源宠物资质
  -> 宠物资质提取器按比例计算
  -> 生成五项资质宝石
  -> 镶嵌到目标宠物资质孔
  -> 写入目标宠物 qualifications.gem
  -> 重新计算宠物属性快照
```

安全边界：

- 已镶嵌宝石提供的资质默认不参与再次提取，避免循环放大。
- 来源宠物在提取时直接消耗，否则可以无限复制资质。
- 来源宠物已绑定时，生成宝石继承不可交易状态。
- 限定宠物的宝石必须校验目标 `templateId`。
- 提取与镶嵌都必须使用事务、请求幂等和实例版本。

提取器已确定为单一档位、按50%提取，来源宠物消耗；宝石拆除规则仍未确定。

## 14. 提资类型与参考公式

`提资计算表`出现的提资类型：

- 四合攻 A 类、四合攻 B 类。
- 四合攻深渊领主、四合攻恶魔武士。
- 四合速 A 类、四合速 B 类。
- 四合速深渊领主、四合速恶魔武士。
- 硬提八四光年、硬提熊猫武圣。
- 二合攻树骑。
- 三合攻巨象、三合攻熊猫。
- 自定义载体与多孔资质宝石。
- 多提一和九提一。

简易计算器中可观察到的参考提取公式：

```text
提出资质 = 红色资质 ÷ 2 + 基础资质 × 1.1 ÷ 2
```

该公式只代表表格当前写法。表格其他位置还使用不同权重、孔位求和和查表数据，并明确注明仅供参考，因此不能直接作为服务端正式规则。

表格作者给出的成本路线摘要：

- 单满攻击：四合攻恶魔武士较省。
- 双满生命/防御：硬提熊猫武圣九提一较省。
- 三满攻击/生命/防御：二合树骑、三合熊猫或巨象后，再用四合宠九提一。
- 五满：四合 A 类提生命/防御后九提一，表中认为 10 孔是百级五满的必要条件。

这些是玩家成本优化结论，不是游戏规则。正式系统只应实现稳定的合成和提取协议，成本最优路线由玩家自行选择。

## 16. 技能资料结论

新补充的成熟宠物面板明确显示“宠物会 12 项技能”，与技能表中的槽位结构完全对应：

| 显示类别 | 数量 | 补充截图实例 |
| --- | ---: | --- |
| 主动神符技 | 1 | S圣技.破坏一击 |
| 英雄神符技 | 1 | 圣技.反噬 |
| 编号神符技 | 3 | 圣技.强壮、圣技.破甲、圣技.精灵守护 |
| 普通技 | 3 | 圣技.巨盾、圣技.暴伤、魂技.无敌飞毛腿 |
| 天生技 | 1 | 帽子魔法 |
| 宠物法宝技 | 3 | 圣技.迅捷、涅槃S圣技、SS圣技.旋风斩 |

因此完整上限确认为 12 项。新获得宠物通常表现为“1 个天生技 + 最多 3 个普通技”，成熟阶段再通过神符和宠物法宝扩展到 12 项。

已确认的技能获得规则：

- 主动神符和英雄神符是道具实例，必须先将兼容的宠物技能卡打入神符，之后才能用于宠物学习对应神符技能；主动神符只接受主动宠物技能卡，英雄神符可接受主动或被动技能卡。技能卡打入后消耗，神符用于宠物学习后神符道具也消耗。
- 野宠所有战斗主动天生技能统一消耗10点精力，非战斗技能不消耗精力。
- 同一技能类别在同一只宠物上只能存在一个，学习、覆盖和穿戴法宝时均由服务端拒绝重复类别。
- 3 个普通技能槽直接使用宠物技能卡学习，由服务端随机命中其中一个槽位，可能新增到空槽，也可能覆盖任意一个已有普通技能。
- 宠物法宝技能卡先打入具体宠物法宝实例。宠物穿上法宝时自动获得其中的法宝技能，卸下后失去；法宝本体不会被消耗，使用另一张技能卡覆盖时旧技能消失，更换法宝即可切换技能。
- 宠物法宝自带1个技能槽；普通锻造达到+15后，使用宠物饰品强化石圣锻达到+5、+10分别解锁第2、第3个位置，最多3个。使用锻造宝石进行圣锻不能解锁第2、第3个位置，且属性数值较低。
- 宠物法宝属性按类型固定：速度普通锻造每级+6、圣锻每级+1%；法力+9/+1%；攻击+50/+1%；防御+50/+1%；生命+500/+1%。圣锻、打孔、注魔均100%成功，材料按1:1消耗；普通锻造规则待定。
- 所有随机学习和卡片消耗必须使用请求幂等与资产流水，重试不得重新随机或重复扣除。

补充截图还显示抗致命、抗暴伤、抗人物和抗宠物等宠物抗性字段，战斗属性快照需要保留这些独立抗性，不能合并进防御。

天生技能覆盖单攻、双攻、群攻、群法、群毒、群体必中、治疗、控制和防御。普通技能推荐只是玩家或界面建议，不应强制写入宠物模板。

截图中的技能名应与 `systems/skill/pet.js`、`systems/skill/common.js` 对照；找不到结构化效果的技能先作为待实现技能，不用旧截图文案临时拼公式。
