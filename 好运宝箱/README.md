# 好运宝箱

该目录集中维护好运宝箱的奖池、概率、价值、图标和元宝商城元数据。

- `shared.js`：服务端与客户端共享的奖池配置和权威抽奖函数。
- 奖励物品统一落入服务端 `lucky_box_items_json`，客户端不能提交或覆盖奖励数量。
- 宝箱通过元宝商城购买，单价 40 元宝；旧银币快速购买已移除。

接口：

- `GET /api/yuanbao-shop/catalog`：返回宝箱和全部商品，只展示元宝价格。
- `POST /api/yuanbao-shop/buy`：服务端校验元宝并购买宝箱或奖池物品。
- `POST /api/lucky-box/open`：服务端事务扣除宝箱并按奖池概率发放物品。
