# 聊天模块

负责游戏内实时聊天的协议校验和菜单聊天 UI 接入。

- WS：`chat.send`，频道为 `nearby`、`server`、`channel`、`team`、`whisper`。
- 身份、角色名、服务器、线路、地图和队伍成员全部取自服务端 socket session metadata，忽略客户端自报字段。
- 单条消息最多 160 字符，服务端执行 800ms 冷却；拒绝使用稳定的 `chatError.error`。
- 客户端仅将纯文本插入 DOM，物品与表情标记在转义后再渲染。
- 表情面板包含原表情页与 `ico.png` 图标表情页；后者按 9 列、5 行、每格 16px 渲染。
- `chat-history-ui.js` 管理井键聊天记录界面：`全部 / 同屏 / 全服 / 全线 / 家族 / 私聊` 的筛选、左右翻页和 `0` 键切换频道；仅读取客户端已接收的聊天记录，不影响服务端聊天授权与投递范围。
- 服务端 `broadcastSystemAnnouncement` 仅由服务端领域结算调用，并按游戏服向在线玩家广播全服系统公告；奖励公告使用服务端生成的 `[item:...]` 标记复用客户端物品渲染，客户端不得伪造该消息。
