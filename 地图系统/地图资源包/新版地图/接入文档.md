# 新版地图资源包接入文档

本目录是从 `map-viewer` 导出的完整新版地图资源包，包含所有地图数据、瓦片素材、世界地图、区域地图、校准点位、传送线、人物测试和浏览器查看器代码。

## 1. 目录结构

```text
新版地图/
  package.json
  server.mjs
  一键启动新版地图.bat
  public/
    index.html
    app.js
    style.css
    data/
      maps.json              # 67 张地图数据、地图标题、传送关系、地图 hex
      external-tiles.json    # 外部 .tij 瓦片数据
      map-points.json        # 区域地图真实点位与区域传送线
      world-points.json      # 世界地图入口点位
    assets/
      d/
        00.png               # 基础瓦片图集
        01.png
        02.png
      c/
        53.chj               # 人物测试精灵/角色动画
      map-art/
        world.png            # 世界地图素材
        sgz.png              # 闪光镇区域图素材
        sgpy.png             # 闪光平原区域图素材
        jlmg.png             # 精灵迷宫区域图素材
```

## 4. 接入普通 Web 项目

把 `public/` 整个目录复制到你的 Web 项目静态资源目录，例如：

```text
你的项目/public/kdjl-map/
  index.html
  app.js
  style.css
  data/
  assets/
```

访问路径示例：

```text
/kdjl-map/index.html
```

前端代码全部使用相对路径：

```text
./data/maps.json
./data/external-tiles.json
./data/map-points.json
./data/world-points.json
./assets/...
```

所以只要保持 `public` 内部结构不变，就可以放到任意静态目录。

## 5. Express 接入示例

```js
import express from 'express';
import path from 'node:path';

const app = express();
app.use('/kdjl-map', express.static(path.resolve('public/kdjl-map')));
app.listen(3000);
```

然后访问：


## 8. 数据文件说明

### `maps.json`

核心地图数据。主要字段：

```json
{
  "maps": [],
  "areas": {},
  "worldMap": {},
  "worldNames": {}
}
```

单张地图主要字段：

```json
{
  "id": 112101,
  "key": "jlmg/101.sj",
  "world": "jlmg",
  "title": "行政区",
  "hex": "...",
  "move": { "x": 6, "y": 9 },
  "teleports": []
}
```

### `map-points.json`

区域图坐标描述文件，坐标是区域素材图片原图像素坐标，原点在左上角。

```json
{
  "coordinateSystem": "source image pixels, origin top-left",
  "areas": {
    "jlmg": {
      "imageSize": { "width": 192, "height": 208 },
      "edges": [],
      "maps": {
        "jlmg/401.sj": {
          "title": "绿色圣地",
          "x": 63,
          "y": 24
        }
      }
    }
  }
}
```

### `world-points.json`

世界图坐标描述文件，坐标是世界地图素材 `world.png` 的原图像素坐标。

```json
{
  "nodes": {
    "sgz": { "name": "闪光镇", "x": 87.4, "y": 119.4 },
    "sgpy": { "name": "闪光平原", "x": 111.4, "y": 143.4 },
    "jlmg": { "name": "精灵迷宫", "x": 135.4, "y": 143.4 }
  }
}
```

## 9. 更新区域点位的流程

1. 用 `map-point-adjuster` 调整点位。
2. 导出 JSON 描述文件。
3. 覆盖本包里的：

```text
public/data/map-points.json
```

4. 刷新浏览器即可看到新区域点位和传送线。

## 10. 注意事项

- 不要改动 `public/data/` 和 `public/assets/` 的相对位置。
- 如果复制到子路径，例如 `/game/kdjl-map/`，无需修改代码。
- 如果放到 CDN，确保 JSON、PNG、CHJ 文件允许被浏览器访问。
- `server.mjs` 只是本地预览服务器，正式项目接入时可以不用。
