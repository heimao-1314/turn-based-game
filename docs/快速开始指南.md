## 环境要求

| 依赖 | 最低版本 | 说明 |
|------|---------|------|
| Node.js | 22.14.0+ | 必须支持 `node:sqlite`；Node.js 18 不支持 |
| Python | 3.8+ | 仅地图预览渲染需要 |
| Pillow | 9.0+ | Python 图像处理库 |

## 快速启动

### 1. 安装依赖

`ash
# Node.js 项目（无 npm 依赖，使用内置模块）
# Python 地图工具依赖
pip install Pillow
`

### 2. 启动服务器

`ash
# 方式一: 使用 npm
npm start

# 方式二: 直接启动
node server.js
`

服务器启动后，默认监听端口 **6588**。

### 3. 访问游戏

在浏览器中打开:

`
http://localhost:6588
`

### 4. 访问管理后台

`
http://localhost:6588/admin.html
`

管理员凭证应在本地 `.env` 中自行设置，参考根目录 `.env.example`；不要依赖开发默认口令，也不要将其用于公网环境。

## Windows 一键启动

双击运行 `一键启动.bat` 即可启动服务器。

停止服务请双击 `停止服务.bat`。

## 配置说明

### 环境变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `PORT` | 6588 | 服务器端口 |
| `ADMIN_PASSWORD` | admin123 | 管理员密码 |
| `REMOTE_ADMIN_ACCOUNT` | admin | 远程管理员账号 |
| `REMOTE_ADMIN_PASSWORD` | zhl8 | 远程管理员密码 |
| `WS_BANDWIDTH_STATS` | (空) | 设为 "1" 启用 WebSocket 带宽统计 |

### 应用配置 (app-config.js)

`javascript
window.APP_CONFIG = {
  serverOrigin: ""      // 服务器地址（离线模式下为空）
};
`

## 开发指南

### 运行测试

`ash
node --test 战斗/engine.test.js
`

### 战斗系统开发

战斗系统采用模块化架构，核心文件位于 `战斗/` 目录:

1. **skills.js** - 添加新技能
   - 在 `skillCatalog` 中添加技能定义
   - 设置技能类型、数值参数和效果

2. **engine.js** - 修改战斗逻辑
   - `calcDamage()` - 伤害计算公式
   - `fighterAction()` - 技能施放逻辑
   - `resolveBattleTurn()` - 回合结算流程

3. **protocol.js** - 修改数据同步格式
4. **session.js** - 修改战斗会话流程

### 组队系统开发

组队系统文件位于 `队伍/` 目录:

1. **runtime.js** - 客户端组队逻辑
2. **联网战斗/runtime.js** - 服务端中心化联网战斗仲裁

## 地图工具链

### 转换地图

`ash
# 批量转换 .sc 地图为 JSON
node 脚本/batch-convert-maps.js
`

输入目录: `maps待接入/`
输出目录: `地图/converted/`

### 渲染地图预览

`ash
python 脚本/render_map_previews.py
`

输出目录: `地图/previews/`

### 生成精灵图清单

`ash
node 脚本/generate-chj-catalog.js
`

输出: `精灵图编号清单.md`

## Android 构建

### 构建加密资源包

`ash
node 脚本/build-resource-pack.js
`

输出目录: `dist-android/assets/resource-pack/`

资源使用 AES-256-GCM 加密，包含:
- 加密的 .dat 资源文件
- manifest.json 清单文件

## 常见操作

### 修改管理员密码

设置环境变量后启动:

`ash
ADMIN_PASSWORD=your_new_password node server.js
`

### 查看玩家数据

1. 访问 `http://localhost:6588/admin.html`
2. 输入管理员密码登录
3. 在"玩家管理"页面查看和编辑玩家数据

### 添加兑换码

兑换码由数据库 `redeem_codes` 管理。通过受控迁移或管理流程创建兑换码、奖励、有效期、全服次数和单账号限额；不要将真实兑换码写进源码或文档。

### 备份数据

数据库文件为 `players.sqlite`，直接复制该文件即可备份。
