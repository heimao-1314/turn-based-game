## 安装与启动

### Q: 启动时报错 `Cannot find module 'node:sqlite'`

**A:** 需要 Node.js 18.0 或更高版本。`node:sqlite` 是 Node.js 内置模块，低版本不支持。

`ash
# 检查 Node.js 版本
node --version

# 推荐使用 nvm 升级
nvm install 18
nvm use 18
`

### Q: 端口 6588 被占用怎么办？

**A:** 设置 `PORT` 环境变量使用其他端口:

`ash
PORT=3000 node server.js
`

### Q: Windows 上双击 `一键启动.bat` 没反应？

**A:** 可能的原因:
1. Node.js 未安装或未加入 PATH
2. 端口被占用
3. 权限不足

建议在命令行中手动运行 `node server.js` 查看具体错误信息。

## 游戏运行

### Q: 页面加载后白屏？

**A:** 检查以下几点:
1. 确认 `app.js` 文件完整（约 385KB）
2. 打开浏览器开发者工具 (F12) 查看控制台错误
3. 清除浏览器缓存后刷新

### Q: 游戏画面不显示精灵图？

**A:** 精灵图文件 (.chj) 需要放在 `精灵图/` 目录下。运行以下命令检查缺失的精灵图:

`ash
node 脚本/generate-chj-catalog.js
`

查看生成的 `精灵图编号清单.md` 中"代码引用但缺文件"部分。

### Q: 地图显示异常？

**A:** 确认地图文件已正确转换:

`ash
node 脚本/batch-convert-maps.js
`

检查 `地图/converted/conversion-summary.json` 中是否有转换失败的地图。

## 战斗系统

### Q: 战斗伤害计算公式是什么？

**A:** 伤害计算公式:

`
raw = hpDamage + attack * attackScale + mana * manaScale + defense * defenseScale + speed * speedScale
effectiveDefense = defense * (1 - pierce)
damageReduction = min(0.9, effectiveDefense / (effectiveDefense + 100000))
final = max(1, raw * (1 - damageReduction) * (1 - guardReduction)) * critMultiplier
`

详细实现参见 `战斗/engine.js` 中的 `calcDamage()` 函数。

### Q: 如何添加新技能？

**A:** 在 `战斗/skills.js` 的 `skillCatalog` 对象中添加技能定义:

`javascript
const skillCatalog = {
  // 现有技能...
  my_new_skill: {
    name: "技能名称",
    type: "physical",        // 技能类型
    attackScale: 2.0,        // 攻击力倍率
    manaScale: 0.5,          // 法力倍率
    targetRule: "all",       // 目标规则 (默认单体)
    // 其他效果参数...
  }
};
`

### Q: 被动技能有哪些类型？

**A:** 被动技能类型:

| 被动效果 | 说明 |
|---------|------|
| `passiveDodge` | 闪避率 |
| `passiveCombo` | 连击（攻击后追加一次普攻） |
| `passiveCounter` | 反噬（受击后反击） |
| `passiveRebirthChance` | 涅磐（死亡时概率复活） |
| `passiveBreakArmor` | 破甲（清除目标防御） |
| `passiveLifesteal` | 吸血（造成伤害时恢复生命） |
| `passiveGuardRole` | 守护角色（减少来自角色的伤害） |
| `passiveGuardPet` | 守护宠物（减少来自宠物的伤害） |
| `passiveGuardMercenary` | 守护佣兵（减少来自佣兵的伤害） |

### Q: 战斗中的状态效果有哪些？

**A:** 状态效果列表:

| 状态 | 说明 | 持续机制 |
|------|------|---------|
| confuse | 混乱（随机攻击） | 回合结束递减 |
| bind | 束缚（无法行动） | 回合结束递减 |
| seal | 封印（无法使用技能） | 回合结束递减 |
| sleep | 沉睡（无法行动） | 回合结束递减 |
| stun | 眩晕（无法行动） | 回合结束递减 |
| paralyze | 麻痹（无法行动） | 回合结束递减 |
| bleed | 流血（持续伤害） | 回合结束递减 |
| curse | 诅咒（持续法力伤害） | 回合结束递减 |
| vulnerable | 虚弱（减伤降低） | 回合结束递减 |
| slow | 减速（速度降低） | 回合结束递减 |

## 多人联机

### Q: 如何与其他玩家对战？

**A:** 在游戏中靠近其他玩家，点击对方角色发起战斗邀请。对方接受后进入战斗。

### Q: 如何组队？

**A:** 发送组队邀请给其他玩家，对方接受后加入队伍。组队后:
- 队伍成员在相同地图时自动参与战斗
- 队伍人数影响野怪数量（1人=1只，4人=14只）
- 联网战斗由服务器统一创建、仲裁和广播

### Q: 联网连接不稳定怎么办？

**A:** 游戏使用 WebSocket 进行通信。如果连接不稳定:
1. 检查网络连接
2. 刷新页面重新连接
3. 关闭其他占用带宽的应用

## 管理后台

### Q: 忘记管理员密码怎么办？

**A:** 设置环境变量重新启动:

`ash
ADMIN_PASSWORD=new_password node server.js
`

或修改 `server.js` 中的默认密码:

`javascript
const adminPassword = process.env.ADMIN_PASSWORD || "admin123";
`

### Q: 如何发放物品给玩家？

**A:** 通过管理后台 API:

`ash
curl -X POST http://localhost:6588/api/admin/grant-item \
  -H "Content-Type: application/json" \
  -d '{
    "adminAccount": "admin",
    "adminPassword": "admin123",
    "targetAccount": "player1",
    "itemId": "item_id",
    "count": 1
  }'
`

### Q: 如何检测异常玩家数据？

**A:** 运行异常扫描:

`ash
curl -X POST http://localhost:6588/api/admin/scan-anomalies \
  -H "x-admin-account: admin" \
  -H "x-admin-password: admin123"
`

然后查看结果:

`ash
curl http://localhost:6588/api/admin/anomalies \
  -H "x-admin-account: admin" \
  -H "x-admin-password: admin123"
`

## 离线模式

### Q: 什么是离线模式？

**A:** 离线模式使用 IndexedDB 作为本地数据存储，无需服务器即可游玩。适用于:
- Capacitor 打包的移动应用
- 本地文件协议 (file://) 访问
- localhost 无端口访问

## 数据与安全

### Q: 数据库在哪里？如何备份？

**A:** 数据库文件为 `players.sqlite`，位于项目根目录。直接复制该文件即可备份:

`ash
cp players.sqlite players.sqlite.backup
`

### Q: 数据库使用什么引擎？

**A:** 使用 SQLite，启用 WAL (Write-Ahead Logging) 模式以提高并发性能:

`javascript
db.exec("PRAGMA journal_mode = WAL;");
db.exec("PRAGMA busy_timeout = 5000;");
`

### Q: 如何防止作弊？

**A:** 服务端包含异常检测系统:
- 属性异常检测（等级/属性不匹配）
- 战斗数据验证
- 管理员可手动扫描和处理异常数据

### Q: 资源包如何加密？

**A:** 使用 `build-resource-pack.js` 构建加密资源包:
- 加密算法: AES-256-GCM
- 密钥派生: SHA-256(固定盐值)
- 输出: 加密的 .dat 文件 + manifest.json
