# 地图兼容与管理员编辑说明

## 目录约定

- 游戏读取地图 JSON：`资源/地图/*.json`
- 新版地图生成器导出目录：`地图生成器/maps/converted/*.json`
- 游戏地图清单与传送规则：`地图系统/地图清单.json`
- 地图兼容模块：`地图系统/map-registry.js`
- 管理员地图接口：`地图系统/admin-map-api.js`
- 游戏内可视化编辑器：`map-admin-editor.js`

## 新增地图流程

1. 将新版地图生成器导出的 JSON 放入 `资源/地图`。
2. 用游戏内管理员账号登录游戏。
3. 点击右上角“地图”按钮。
4. 点击“扫描新地图”。
5. 新 JSON 会按文件名自动登记到 `地图系统/地图清单.json`。

登记后的地图会出现在世界地图菜单中，默认入口坐标为 `(1, 1)`，可直接编辑 `地图系统/地图清单.json` 调整 `entry` 和 `desc`。

## 管理员账号

默认游戏内管理员账号：

```text
账号：mapadmin
密码：mapadmin2026
```

可通过环境变量覆盖：

```text
GAME_ADMIN_ACCOUNT=你的账号
GAME_ADMIN_PASSWORD=你的密码
```

这个账号只用于游戏内地图编辑，不等同于 `admin.html` 管理后台权限。

## 传送规则

传送规则存放在 `地图系统/地图清单.json` 的 `portals` 数组：

```json
{
  "from": "仓库",
  "x": "*",
  "y": "max",
  "direction": "down",
  "to": "原野怪区",
  "toX": "$x",
  "toY": 1
}
```

字段说明：

- `from`：来源地图名。
- `x` / `y`：来源像块坐标，支持数字、`*`、`max`。
- `direction`：触发方向，支持 `up/down/left/right/*`。
- `to`：目标地图名。
- `toX` / `toY`：目标像块坐标，支持数字、`$x`、`$y`、`max`、`max-1`。

旧版硬编码传送已经迁移为默认配置，后续新增传送不需要再改 `app.js`。

## 模块边界

- `server.js` 只负责挂载地图 API 和创建默认管理员账号。
- `地图系统/map-registry.js` 负责读取、扫描、校验和保存地图清单。
- `地图系统/admin-map-api.js` 负责管理接口。
- `app.js` 只负责读取地图清单和执行传送规则。
- `map-admin-editor.js` 只负责游戏内可视化编辑 UI。
